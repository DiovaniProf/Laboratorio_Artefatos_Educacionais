# Observatório de Práticas IA — Recursos Digitais 2.0

## Conteúdo
- `index.html`
- `styles.css`
- `script.js`
- `GOO.jpg`

## Como usar no GitHub Pages
1. Envie todos os arquivos para a raiz do repositório.
2. Mantenha a imagem `GOO.jpg` na mesma pasta do `index.html`.
3. Ative o GitHub Pages apontando para a branch principal.

## Observação
A **primeira capa no canto superior esquerdo** foi reservada para a imagem `GOO.jpg`, conforme solicitado.
Toda a moldura, luzes, textos e botões são produzidos por **HTML, CSS e JavaScript**.
